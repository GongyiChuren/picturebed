# 中文图床站

这是一个用于 GitHub Pages 的静态中文图床站。

## 使用方式

1. 把图片放到 `images/` 文件夹。
2. 把项目推送到 GitHub 仓库。
3. 在仓库 `Settings -> Pages` 里开启 GitHub Pages。
4. 使用下面格式访问图片：

```text
https://用户名.github.io/仓库名/images/图片名.png
```

## 是否需要 Cloudflare

普通个人图床不需要 Cloudflare。只有在需要自定义域名、缓存加速、隐藏 `github.io` 地址，或访问量较大时，再考虑接入 Cloudflare。

## 注意

- 不建议存放大量超大图片或视频。
- 上传前建议压缩图片，减少仓库体积和访问流量。
