部署步骤

  1. 把这个文件夹推送到 GitHub 仓库。
  2. 进入仓库 Settings → Pages。
  3. 选择分支和根目录，保存后等待部署完成。
  4. 打开 GitHub Pages 地址，测试图片链接是否能访问。
